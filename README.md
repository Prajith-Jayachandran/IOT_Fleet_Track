# IoT Fleet Tracking Project
This is a database management system (DBMS) mini project for college.
It simulates an IoT fleet tracking system for vehicles.

## Features
- Vehicle Management
- Driver assignment
- Live map tracking (using Leaflet)
- Analytics dashboard
- Custom database engine for mock data

## How to run
1. Install nodejs
2. Open terminal in this folder
3. Run `npm install`
4. Run `npm start`
5. Open http://localhost:5005 in browser

## Technologies used
- Frontend: HTML, CSS, JS
- Backend: Node.js, Express
- Database: MySQL (with local mock data fallback)
